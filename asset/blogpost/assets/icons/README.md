The Simple Icons [license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) is [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Brand trademarks remain with their respective owners. Hugging Face retains its brand rights under its [terms](https://huggingface.co/terms-of-service).

arXiv and GitHub use `fill="currentColor"` and `viewBox="0 0 24 24"`. Hugging Face retains its original colors and uses `viewBox="0 0 95 88"`, matching its source canvas. Fixed dimensions were removed, and a title was added to the Hugging Face SVG.

Inline use is recommended so the monochrome icons inherit link color. When shown beside a visible resource label, add `aria-hidden="true"` and `focusable="false"` to the inline SVG. All three files contain only SVG roots, titles, and paths, with no scripts, event handlers, remote references, or foreign objects.
